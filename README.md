# svelte-book-okf

An **[OKF](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md) knowledge bundle** of [https://svelte.dev/docs](https://svelte.dev/docs) — ready for agents to read and for you to chat with.

```bash
pip install okf-kit
okf get svelte-book
okf chat svelte-book --provider ollama
```

Built and kept fresh with [okf-kit](https://github.com/vinodborole/okf-kit).
